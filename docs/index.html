Topic-FM · Dirichlet topic VAE · public code

PanODE-Topic

This repository implements Topic-FM and Pure-VAE model families for single-cell representation learning. The page describes the public code. It is not a journal article.

What this code implements

A neural topic VAE with simplex topic proportions, a decoder β matrix, and optional flow-matching refinement.

The public tree contains model code, benchmark runners, and evaluation utilities. No article DOI is assigned.

Run

python benchmarks/runners/benchmark_base.py --series topic --data-path <dataset-path>
python benchmarks/runners/benchmark_base.py --models Topic-FM-Transformer Pure-VAE --data-path <dataset-path>
python benchmarks/runners/benchmark_crossdata.py --datasets <dataset-key> <dataset-key>

Pass a local dataset with --data-path for single-dataset runs. Cross-dataset runs need registry keys aligned on the machine that executes them.
